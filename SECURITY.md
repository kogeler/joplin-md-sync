# Security Policy

## Reporting

Report suspected vulnerabilities via GitHub private vulnerability reporting
(Security tab) on this repository. Do not open public issues for security
problems.

## Security model

The test-backed security requirements are in the
[security contract](docs/contracts/SECURITY.md). Threat assumptions, trust
boundaries, and residual risks are explained in
[Security rationale](docs/maintenance/SECURITY.md). Deployment procedures are
in [Self-hosted deployment](docs/user/SELF_HOSTED.md) and
[Service operations](docs/user/SERVICE.md).
